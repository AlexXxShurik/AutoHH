# AutoHH

Автоматическое поднятие резюме на [hh.ru](https://hh.ru) / [hh.kz](https://hh.kz). Сервис каждый час проверяет, доступна ли кнопка «Поднять резюме в поиске», и кликает её, как только это возможно.

## Как это работает

1. **Вход в аккаунт** — выполняется через Selenium: на странице входа выбирается вкладка «Почта», вводится email, после чего у пользователя запрашивается 4-значный код подтверждения. При необходимости (капча и т.п.) вход завершается вручную в открытом браузере. Куки сохраняются в файл и переиспользуются при следующих запусках.
2. **Планировщик** — на базе [taskiq](https://taskiq-python.github.io/): при старте задача выполняется сразу, затем — по расписанию cron (по умолчанию каждый час).
3. **Поднятие резюме** — на главной странице ищется кнопка `[data-qa="applicant-index-nba-action_update-resumes"]` и кликается, если она доступна.

> Кнопка «Поднять» отображается только при ширине окна ≥ 1024px, поэтому браузер принудительно открывается в окне 1366×900.

## Установка

Требуется Python 3.11+ и [Poetry](https://python-poetry.org/).

```bash
git clone <url>
cd AutoHH
poetry install
```

## Настройка

Скопируйте шаблон конфигурации и заполните его:

```bash
cp .env.example .env
```

| Переменная       | Описание                                        | По умолчанию        |
| ---------------- | ----------------------------------------------- | ------------------- |
| `BASE_URL`       | Базовый адрес сайта (hh.ru / hh.kz)             | `https://hh.ru`     |
| `HH_EMAIL`       | Email аккаунта для входа                        | —                   |
| `COOKIES_FILE`   | Файл с сохранёнными куки авторизации            | `cookies.pkl`       |
| `CRON`           | Расписание проверки (cron-выражение)            | `0 * * * *`         |
| `TZ`             | Часовой пояс для расписания                     | `Asia/Almaty`       |
| `HEADLESS`       | Режим без окна браузера (`true`/`false`)        | `true`              |

Для первого входа (подтверждение по коду / капча) используйте `HEADLESS=false`.

## Запуск

```bash
poetry run python scheduler.py
```

При старте резюме будет подниматься сразу (если возможно), далее проверка выполняется по расписанию.

## Структура проекта

```
AutoHH/
├── scheduler.py          # Точка входа: запуск задачи и планировщика
├── app/
│   ├── config.py         # Настройки из .env
│   ├── driver.py         # Создание Selenium WebDriver
│   ├── auth.py           # Авторизация (email + OTP-код), работа с куки
│   ├── resume.py         # Логика поднятия резюме
│   └── tasks.py          # taskiq-задачи, broker и scheduler
├── .env.example          # Шаблон конфигурации
└── pyproject.toml        # Зависимости (Poetry)
```
